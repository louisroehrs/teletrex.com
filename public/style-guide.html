Usage notes

Do
Use the teal accent sparingly — links, primary CTAs, active indicators, and key data callouts only.
Don't
Use the accent color for decorative fills, large background areas (except section headers), or more than one CTA per screen.

Links

Inline links use accent color with an invisible underline that appears on hover. Font weight stays at the parent's weight — do not bold links mid-sentence.

Transition timing

All interactive transitions use transition: 0.15s ease. Apply to: color, background-color, box-shadow, border-color, opacity, text-decoration-color.

Logo watermark

The inverted transparent logo is used as a full-page watermark via body::before at min(640px, 120vmin) size, centered, opacity: 0.8. Asset: teletrex large inverted transparent.png

CSS Design Tokens

Copy this :root block into any project to inherit the full TeleTrex system.

:root {
  /* Colour */
  --color-bg:           #faf8f5;
  --color-surface:      #ffffff;
  --color-text:         #1c1917;
  --color-text-muted:   #57534e;
  --color-accent:       #0f766e;
  --color-accent-hover: #0d9488;
  --color-border:       #e7e5e4;
  --color-light-teal:   #f0fdfa;

  /* Typography */
  --font-display: 'Fraunces', Georgia, 'Times New Roman', serif;
  --font-body:    'Plus Jakarta Sans', system-ui, sans-serif;

  /* Border radius */
  --radius-sm:   0.375rem;   /*  6px */
  --radius-btn:  0.5rem;     /*  8px */
  --radius-card: 0.75rem;    /* 12px */
  --radius-lg:   0.875rem;   /* 14px */

  /* Shadows */
  --shadow-card:   0 1px 2px rgba(28,25,23,.04);
  --shadow-float:  0 8px 24px rgba(28,25,23,.08);
  --shadow-deep:   0 4px 6px -1px rgba(28,25,23,.07),
                   0 12px 32px -4px rgba(28,25,23,.12);
  --shadow-accent: 0 0 0 1px rgba(15,118,110,.15);
  --shadow-btn:    0 1px 2px rgba(28,25,23,.08);

  /* Motion */
  --transition: 0.15s ease;

  /* Layout */
  --max-width: 52rem;
}

Voice & Tone

How TeleTrex sounds in words mirrors how it looks visually — precise, warm, and never overblown.

Do
Direct & confident. "Accurate transcripts, seconds after your call ends."

Warm but not casual. "We built this because we were tired of taking notes."

Specific. Name the benefit, not the feature. "Save two hours per meeting" beats "advanced AI processing."
Don't
Hype language. Avoid "revolutionary," "game-changing," "disruptive," or "10×."

Jargon for its own sake. Don't lead with tech — lead with the outcome.

Passive voice. "Meeting notes are generated" → "We generate your meeting notes."
AttributeDescription
ConfidentStates outcomes clearly. No hedging or excessive qualifiers.
PrecisePrefers specific numbers and concrete benefits over vague claims.
WarmHuman, not corporate. Acknowledges real problems teams face.
EconomicalShort sentences. No filler. Every word earns its place.
TrustworthyNever oversells. Lets the product speak through specifics.
